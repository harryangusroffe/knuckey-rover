# Knuckey Rover

Project website for the Knuckey Rover, an RMIT University engineering capstone (OENG1167/OENG1168, 2026)
built with Knuckey Agricultural Engineering of Winchelsea, Victoria.

Live at https://harryangusroffe.github.io/knuckey-rover/

Static HTML, CSS and JavaScript with no build step. Figures come from the team's final report and the
13–14 October 2026 field test records; every number on the site is tagged with its source.

Team: Isabella Calder, Manas Desai, Alexander McIntosh, Morne Nel, Harry Roe, Harry Roffe.
Supervisor: Dr Amirali Khodadadian Gostar.
