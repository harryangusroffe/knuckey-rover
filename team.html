How we worked

Narrow nodes, agreed interfaces

The software is a set of ROS 2 nodes with narrow jobs, so ownership split cleanly along node boundaries. Before integrating, we agreed topic names, message types and sign conventions between nodes, and an interface review in October caught mismatches before the outdoor tests.

The hardware went the other way. Driveline, wheels and the 48 V power system became a collective build to one electrical design, with everyone on the bench.

Simulation results were recorded one attempt per configuration, with the repository commit noted and no tuning between attempts. That limits the chance of reporting a lucky run.

Next year

Want to work on it?

The Knuckey Rover continues with future RMIT capstone teams. The hard build is done, so next year's work is autonomy on a machine that already drives. You don't need to arrive knowing robotics.
